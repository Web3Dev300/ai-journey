# AI Journey

A structured repository tracking the learning journey in Artificial Intelligence, Machine Learning, and Mathematics.

## Repository Structure

```text
.
├── 01_python_numpy/
│   └── fc_numpy_class.ipynb         # Python & NumPy foundational concepts (N-D arrays, operations)
├── 02_math_and_stats/
│   ├── linear_algebra.ipynb         # Vectors, matrices, transformations, and linear algebra
│   ├── probability.ipynb            # Probability concepts, distributions, Bayes' theorem
│   └── statistics.ipynb             # Descriptive & inferential statistics for ML
├── 03_machine_learning/
│   ├── gradient_descent.ipynb       # Optimization algorithms and gradient descent
│   └── naive_bayes_classifier.ipynb # Naive Bayes classification model implementation
├── data/
│   └── social_network_ads.csv       # Datasets used across machine learning experiments
├── .gitignore                       # Ignored files (checkpoints, environments, OS files)
└── README.md
```

## Getting Started

### Prerequisites

Make sure you have Python 3 and Jupyter Notebook or JupyterLab installed:

```bash
pip install jupyter numpy pandas matplotlib scikit-learn
```

### Running the Notebooks

Launch Jupyter Notebook from the root directory:

```bash
jupyter notebook
```
